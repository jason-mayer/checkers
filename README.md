# checkers

A simple checkers game. [Play it here](https://jasonmayer.me/checkers). [How to play](./how-to-play.md).

A minified HTML file is available under the releases tab, or you could minify it yourself:

1. Clone this repo
2. run `npm install` (requires [node.js](https://nodejs.org/en))
3. run `npm run build`
